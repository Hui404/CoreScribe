# CoreScribe
基于 STM32 + FreeRTOS + LVGL 开发的 CoreXY 结构绘图仪（写字机）项目，包含完整的硬件设计、底层驱动、运动控制逻辑与上位机通信功能，是嵌入式软硬件结合的实战项目。

👉 项目配套详解博客：[https://www.xuuuu404.com/](https://www.xuuuu404.com/)  
（博客内包含从 PCB 设计、硬件调试到软件移植的全流程开发记录）

## 📋 项目简介
CoreScribe 是一款面向嵌入式开发者的开源 CoreXY 绘图仪项目，核心目标是通过实战完成「硬件设计 → 底层驱动 → 系统移植 → 运动控制 → 人机交互」的全链路开发，覆盖 STM32 开发的核心知识点：
- 硬件：CoreXY 机械结构、STM32 最小系统、步进电机驱动、串口/触摸屏外设
- 软件：FreeRTOS 任务管理、LVGL 图形界面移植、Grbl 运动控制协议适配、CoreXY 运动学解算

## 🛠️ 硬件环境
| 组件     | 型号/规格                      |
| -------- | ------------------------------ |
| 主控芯片 | STM32F407VET6                  |
| 电机驱动 | TMC2209 步进电机驱动模块       |
| 机械结构 | CoreXY 运动结构（2路步进电机） |
| 外设     | 触摸屏（LVGL 适配）            |
| 供电     | 12V DC 电源                    |

## 📚 软件环境
- 开发工具：Keil MDK5 / STM32CubeMX
- 系统内核：FreeRTOS V10.4.3（静态/动态任务配置）
- 图形库：LVGL V8.3（移植适配 STM32 硬件屏）
- 通信协议：串口（Grbl 指令集适配）
- 编译环境：ARM GCC / MDK 编译器
